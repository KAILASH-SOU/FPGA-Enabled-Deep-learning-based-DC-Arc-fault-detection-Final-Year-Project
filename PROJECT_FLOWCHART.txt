SECTION 2: DETAILED STEP-BY-STEP BLOCK SPECIFICATIONS
========================================================================================

Use this section to understand what each shape and block in your drawing represents:

BLOCK 1: DATA ACQUISITION & SENSING
- Shape: Parallelogram (Input Data)
- Details: Current sensor samples AC line at 8,000 Hz (8 kHz). One 50 Hz power cycle
  takes 20.0 ms, producing a window of exactly 160 current samples.
- Classes: Class 0 = Normal AC current; Class 1 = Dangerous series arc fault current
  (characterized by zero-crossing shoulder delays and high-frequency chaotic bursts).

BLOCK 2 & 3: DUAL-DOMAIN PREPROCESSING & FEATURE CONCATENATION
- Shape: Rectangle (Process)
- Time Domain: Normalizes raw current amplitudes to [-1.0, +1.0] using 99.9th percentile peak scaling.
- Frequency Domain: Computes 160-point Fast Fourier Transform (FFT). Attenuates DC spike
  at bin 0 by 0.1x to prevent masking subtle high-frequency harmonic energy. Normalized to [0.0, 1.0].
- Output: Concatenated feature vector of 320 dimensions per frame.

BLOCK 4: DATA SPLITTING & STRATIFICATION
- Shape: Rectangle (Process)
- Total Dataset: 100,000 current cycles.
- Split Ratio: 70% Training (70,000), 15% Validation (15,000), 15% Testing (15,000).
- Stratification: Maintains exact 50/50 balance of normal and arc frames across all subsets.

BLOCK 5: ARCHITECTURE & HYPERPARAMETER SEARCH
- Shape: Diamond / Rectangle (Sub-process)
- Automated grid exploration across learning rates (0.001 to 0.008), weight decays (1e-4, 1e-5),
  and dropouts (0.1 to 0.3). Selected configuration: LR=0.003, Weight Decay=1e-4, Dropout=0.20.

BLOCK 6: FPGA-CONSCIOUS 1D-CNN ARCHITECTURE
- Shape: Subroutine Box (Double Border)
- Layer 1: Conv1D (1 in, 16 out, kernel=5, padding=2) -> BatchNorm -> ReLU6 -> MaxPool(2)
- Layer 2: Conv1D (16 in, 32 out, kernel=3, padding=1) -> BatchNorm -> ReLU6 -> MaxPool(2)
- Layer 3: Conv1D (32 in, 32 out, kernel=3, padding=1) -> BatchNorm -> ReLU6 -> MaxPool(4)
- Dense Layer: Linear (640 in, 32 out) -> ReLU6 -> Dropout(0.20)
- Output: Linear (32 in, 1 out) -> Sigmoid Activation -> Probability of Arc Fault [0.0, 1.0].
- Hardware Features: Bounded ReLU6 (clamps activations to [0, 6] to prevent fixed-point overflow),
  power-of-two channel widths (16, 32) matching FPGA memory buses. Total parameters = 23,713.

BLOCK 7 & 8: FP32 BASELINE TRAINING & EVALUATION
- Shape: Rectangle (Process)
- Trained for 12 epochs using Adam optimizer and ReduceLROnPlateau scheduler.
- Baseline Result: Accuracy = 85.90%, F1-Score = 0.8417, Precision = 0.9595, Recall = 74.96%.

BLOCK 9, 10, 11: QUANTIZATION PIPELINE (PTQ VS QAT COMPARISON)
- Shape: Decision Branch (Split into two comparative paths)
- Path A (PTQ): Takes trained FP32 model and directly rounds weights to 8-bit integers without
  retraining. Result: Accuracy crashes to 70.73% and Recall plummets to 43.71% due to accumulated
  rounding error. Proves why simple post-quantization is insufficient.
- Path B (QAT): Implements Straight-Through Estimators (STE). Forward pass simulates 8-bit
  integer quantization; backward pass updates floating-point shadow weights to learn resilience
  to rounding errors. 5 epochs of fine-tuning with CosineAnnealingLR.
  Result: Accuracy recovers to 86.51% and Recall surges to 87.29% with zero hardware penalty!

BLOCK 12: ACADEMIC BENCHMARKING & VISUALIZATION
- Shape: Document / Display
- Automatically outputs 6 high-resolution publication PNG plots:
  1. Waveforms and FFT Spectra (01_dataset_signal_analysis.png)
  2. Training/Validation Convergence (02_training_validation_curves.png)
  3. Side-by-side Confusion Matrices (03_confusion_matrices.png)
  4. ROC-AUC and PR Curves (04_roc_pr_curves.png)
  5. Multi-metric Bar Comparison (05_model_comparison_bar.png)
  6. Weight Quantization Histograms (06_weight_distribution_quantization.png)

BLOCK 13, 14, 15: HARDWARE SYNTHESIS & FPGA DEPLOYMENT
- Shape: Cylinder (Database / Export File)
- Memory: Compresses weights by 75.0% (94.8 KB down to 23.7 KB).
- BRAM: Fits 100% inside 6 tiles of 36Kb Block RAM (< 5% of Xilinx Artix-7 100T).
- Execution: 16 parallel DSP48E1 slices at 100 MHz clock achieve 0.336 ms trip latency.
- Export: Generates C/C++ header (fpga_weights_int8.h) and Vivado COE (fpga_weights_int8.coe).
